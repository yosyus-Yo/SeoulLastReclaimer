# 구로 현장 기록 · Web visual field study

실사풍 재질과 조명에 기반한 **첫 챕터 웹 3D 프로토타입**입니다. 귀환광장과 3개 출동 구역, 주요 미션 3개, 동료 의뢰 4개를 포함합니다. 기존 Unity 게임의 전체 이식본이 아니며 Unity 폴더와 디자인 패키지는 별도로 유지합니다.

## 실행

Node.js 22.12 이상 권장. 이 `web` 폴더에서:

```sh
npm ci
npm run dev
```

[로컬 데모 열기](http://127.0.0.1:5178/)

첫 실행 자료가 이미 `public/assets`에 포함되어 있습니다. 자료를 다시 받아야 할 때만 `node scripts/fetch-assets.mjs`를 실행합니다. 이 명령은 공개 출처에서 필요한 파일만 내려받고 체크섬을 검증합니다.

## 체험

‘광장으로 들어가기’ → J로 출동 게시판 열기 → 물류센터 귀환 출동. 이후 미션은 앞선 미션을 완료하면 열립니다. 새 구역의 지형만 보고 싶다면 ‘둘러보기’를 사용합니다. 자유탐방에는 전투·미션·의뢰 보상이 없습니다.

광장에서는 좌측 상단에 짧은 안전 구역 안내와 J/E 조작만 표시합니다. 체력·방벽·조사 진행·전투 집계는 출동 구역의 패널에서 표시하며, 광장의 자세한 임무·보상은 J에서 확인합니다.

창 단축키는 토글 방식입니다. J는 임무 창 열기/닫기, P는 촬영 모드 켜기/끄기, Esc는 설정 열기/닫기(일반 대화창에서는 그 창 닫기, 촬영 중에는 촬영 종료)입니다. 사망 화면은 재출동 버튼으로 나갑니다. 입력·선택 필드와 한글 조합 중에는 창 단축키를 가로채지 않습니다. 앞으로 추가하는 창 키도 `panelShortcuts`에 등록해 같은 규칙을 사용합니다.

단축키 회귀 검증: 반복 열기/닫기, 키 누름 유지, 다른 모달 중복 방지, 입력·IME·브라우저 조합키 보호 4개 테스트를 추가해 총 47개가 통과했습니다. 실제 브라우저에서도 J/P/Esc 토글과 임무 창 안에서 P가 차단되는 것을 확인했습니다.

| 구역 | 주요 미션 | 실제 진행 |
|---|---|---|
| 귀환광장 | 안전 거점 | 백기석·서린·미라·도윤 대화, 의뢰 수락·보고, 출동 선택 |
| 구로 물류센터 | M001 물류센터 귀환 | 잔향 3개 조사와 위협 제거 → 지지점 2개 Q 설치 → 7명 대피와 추가 위협 제거 → 앵커 융합체 → 남쪽 귀환 확인 |
| 구로새빛학교 | M002 학교의 안전선 | 복도 신호 3개와 위협 확인 → 지지점 2개 → 12명 대피와 방어 → 남쪽 교문 귀환 |
| 태산 기록 보관구역 | M003 남겨진 원본 | 원본 기록 3개 확보와 위협 제거 → 강화 융합체 → 기록 반출·귀환 |

주요 미션 보상은 400/550/800 C이며 각각 최초 완료에만 지급합니다. 반복 출동은 가능하지만 중복 보상은 없습니다. 구조 시간은 이번 축소 프로토타입에서 12초/16초이며 원안의 20~25분 완성 콘텐츠를 의미하지 않습니다. 구조된 인물은 중앙 통로를 따라 남쪽 출구로 이동합니다. 구조대의 실제 경로 탐색 AI 대신 안전한 고정 경로를 사용합니다.

동료 의뢰는 **두고 온 장비**(공구함 2개), **응급실까지 닿는 손**(보급품 3개), **명단에서 지워진 이름**(명패 3개), **광장에 다시 켜진 불**(배전함 3개)입니다. J 또는 동료 대화로 수락한 뒤 현장에서 E로 회수/복구하고, 광장의 해당 동료 곁에서 E로 대화하여 ‘완료 보고’를 누릅니다. 의뢰별 보상은 80/120/150/60 C입니다.

| 입력 | 행동 |
|---|---|
| WASD | 화면 방향 기준 이동 |
| 마우스 우클릭 | 선택한 지점까지 자동 이동. 차량·상자 우회 |
| 마우스 좌클릭 / 유지 | 마우스 방향 파편격 / 반복 공격 |
| Shift | 달리기 |
| E | 대화·게시판·퀘스트 물품·잔향·구급함·귀환 확인 |
| Q | 정면 방어 / 구조 단계에서는 가까운 지지점 설치 |
| J | 주요 미션·동료 의뢰·보상 확인 |
| 우측 위 ⌂ | 광장 귀환. 미완료 현장은 초기화 안내 후 이동 |
| Space | 짧은 회피 이동 |
| P / 촬영 모드 버튼 | 인물 이동을 멈추고 드래그로 카메라 회전 |
| 마우스 휠 | 확대·축소 |
| Esc / 우측 위 설정 | 그래픽 품질, 새벽빛, 노면 젖음, 환경음 |

‘기본 재질과 비교’는 **현재 웹 장면의 스캔 재질과 노면 반사**를 켜고 끕니다. Unity 화면이나 다른 엔진의 품질을 비교하는 기능은 아닙니다.

PC 키보드·마우스용입니다. 작은 화면에 UI가 맞춰지지만 터치 조작은 아직 없습니다. **완료 미션, 수락/완료 의뢰, 의뢰 물품, 보상은 localStorage의 `slr.chapter-one.v1`에 저장**됩니다. 새로고침하면 이 진행을 유지한 채 광장에서 시작합니다. 미완료 현장의 위치·적·조사·구조 단계는 재출동 시 초기화됩니다. 임무 도중 광장으로 돌아갈 때도 이 내용을 먼저 안내합니다. 브라우저 데이터 삭제 또는 다른 브라우저 사용 시 저장은 공유되지 않습니다.

우클릭 목적지는 연두색 원으로 표시하며 도착하면 멈춥니다. 다시 우클릭하면 새 목적지로 바뀝니다. 물체 안이나 도로 밖을 누르면 가까운 이동 가능 지점을 선택합니다. WASD·회피 입력, 설정·촬영 모드 진입, 창 포커스 이탈은 자동 이동을 취소합니다. Shift로 우클릭 이동 중에도 달릴 수 있습니다.

## 기초 전투와 상호작용

- 파편격: 사거리 6.5m, 간격 0.45초, 기본 피해 20, 에너지 소모 없음. 가장 먼저 맞은 대상 1개에 피해를 주며 건물·차량·상자를 통과하지 않습니다. 포격형에는 방어력 보정으로 18 피해입니다.
- 잔금막: 내구도 70, 정면 100도, 3초 유지, 재사용 4초. Q를 누른 시점의 마우스 방향으로 설치합니다. 후방 공격은 막지 못하며 내구도를 넘는 피해만 체력으로 전달합니다.
- 구조 지지점: 해당 단계에서 가까이 서서 Q를 쓰면 20 에너지를 소비해 고정합니다. 고정된 지지점은 임무 내내 유지됩니다. 에너지가 부족하면 북쪽 구조 장비 곁에서 E로 40까지 충전할 수 있습니다.
- 적: 돌진형 2체(HP 60, 0.9초 예고, 피해 18), 포격형 1체(HP 90, 1.1초 고정 위치 예고, 피해 24). 주황색 공격 예고를 보고 이동하거나 방어합니다. 화면 밖 적은 새 공격을 시작하지 않습니다.
- 각 현장에 기본 적 3체를 배치하며 구조 단계에 추가 돌진형 2체가 진입합니다. M001 융합체는 HP 180, M003 강화 융합체는 HP 240이며 현재는 돌진 원형의 확대 모델/행동을 사용합니다. 원안 BS001의 모든 보스 패턴을 이식한 상태는 아닙니다.
- 처치 시 잔향 에너지 18을 남깁니다. E로 회수하며 최대 에너지를 초과하는 잔량은 보존합니다.
- 잔향 용기 2개: HP 40, 공격으로 파괴하면 에너지 25를 남깁니다.
- 출발점 구급함: E로 체력 50 회복, 한 번만 사용 가능. 체력이 가득 차 있으면 소비하지 않습니다.
- Space 회피 중에는 피해를 받지 않습니다. 체력이 0이 되면 재출동 화면을 표시하며, 재시작 시 플레이어·적·잔향·용기·구급함을 모두 초기 상태로 복원합니다.
- 설정과 촬영 모드는 전투를 멈춥니다. 기본 발사와 피격 효과는 절차형 VFX이며 최종 전용 공격 모션은 아직 없습니다.

## 맵 경계

구역별 이동 가능 범위와 충돌 장애물은 `src/zones.js`가 관리합니다. 그 밖에는 통제선, 상가, 이어지는 도로, 먼 도시 건물이 존재하지만 이동할 수 없습니다. 배경 지면은 800×800m, 하늘 돔은 반경 180m로 제작했고 카메라의 최대 줌아웃/회전 범위를 포괄합니다. 각 구역은 광장을 거치는 로딩 전환으로 연결되며 심리스 오픈월드는 아닙니다.

## 그래픽과 PC 부하

기본은 **균형 / 최대 60 FPS**입니다. 설정에서 품질과 30/60 FPS 상한을 독립적으로 고릅니다. `slr.graphics.v1`에만 저장하며 캠페인 저장과 분리합니다. 설정·게시판·시작 메뉴는 최대 30 FPS, 숨겨진 문서는 렌더링을 건너뜁니다. 프레임 상한은 달성 보장이 아닙니다.

| 품질 | 최대 픽셀 배율 | 반사 해상도 / 최대 갱신 | 그림자 해상도 / 최대 갱신 | 후처리 |
|---|---|---|---|---|
| 성능 우선 | 1× | 256px / 10Hz | 1024px / 10Hz | 없음 |
| 균형 (기본) | 1.25× | 512px / 20Hz | 2048px / 15Hz | 약한 빛 번짐 |
| 고화질 | 1.5× | 1024px / 30Hz | 2048px / 20Hz | 빛 번짐 + 출동 구역 SAO |

배율은 장치 DPR 이하로 제한합니다. 1.5×는 1× 대비 픽셀 수가 2.25배이며, 고화질의 반사·SAO도 추가 렌더링 비용을 씁니다. 새 나무는 정적 재질 배치로 합쳐 그리며 수면은 픽셀 셰이더로 처리합니다. 별도 물리 시뮬레이션·실시간 레이트레이싱·고비용 피사계 심도는 추가하지 않았습니다. 낮은 반사 갱신률에서는 움직이는 반사가 덜 매끄럽게 보일 수 있습니다.

실제 로컬 브라우저의 짧은 확인에서는 광장 균형/고화질이 약 60 FPS, 성능 우선·30 제한이 30 FPS였습니다. 같은 물류센터 자유탐방 화면에서는 고화질 36 FPS, 균형 54 FPS를 관찰했습니다. 장치·창 크기·시점에 따른 참고값일 뿐 전체 미션/장시간 벤치마크나 CPU/GPU 사용률·온도 측정은 아닙니다. 발열·팬 소음이 부담스러우면 성능 우선과 30 FPS를 사용하세요.
