# 귀환광장 NPC 디자인 v1

기존 캐릭터 설정서와 모델 참고 시트를 바탕으로 광장 NPC 4명을 실사풍으로 재디자인합니다.

| 인물 | 구분할 특징 | 기준 신장 |
|---|---|---|
| 백기석 | 54세의 낡은 주황 안전조끼, 희끗한 머리, 손전등과 작업수첩 | 173cm |
| 한서린 | 29세의 묶은 머리, 청록 응급 재킷, 의료 가방 | 170cm |
| 오미라 | 35세의 짧은 단발, 갈색 실무복, 서류 가방과 수첩 | 168cm |
| 강도윤 | 31세의 넓은 어깨, 흑연색 구조 하네스, 주황 어깨 패널 | 185cm |

원화는 built-in image_gen으로 제작합니다. 전체 프롬프트와 원본 참고 시트는 [prompts.json](prompts.json)에 기록합니다. 기존 디자인 시트는 덮어쓰지 않습니다.

## 적용 상태

원화 4개, 인물 갤러리, NPC 대화 이미지, 광장 NPC 교체를 완료했습니다. 최초 이미지 생성 도구가 반환한 원본은 체크무늬를 포함한 RGB PNG였으며, 사용자 승인 후 로컬 rembg의 `birefnet-general-lite` 모델로 배경을 제거했습니다. 원본 시안은 보존했습니다.

실제 적용 파일은 [백기석](kiseok-cutout-v1.png), [한서린](seorin-cutout-v1.png), [오미라](mira-cutout-v1.png), [강도윤](doyun-cutout-v1.png)입니다. 네 파일 모두 실제 RGBA 투명도를 포함합니다. 해상도·투명 픽셀 비율·발 기준점·SHA-256은 [cutouts.json](cutouts.json)에 기록했습니다.

광장 NPC는 전신 PNG를 사용하는 2.5D 캐릭터입니다. 발 위치를 지면에 맞추고 설정 신장 173/170/168/185cm를 적용했습니다. 카메라 방향으로 회전하는 세로 평면이므로 전용 3D 메시·리그·뒷모습·표정 애니메이션 제작과는 구분합니다. 광장 NPC에만 적용하며, 주인공과 구조 인물은 기존 구현을 유지합니다.

## 재현과 검증

`web/scripts/prepare-npc-cutouts.py`가 로컬 배경 제거와 여백·발 기준점 계산을 수행합니다. Python 3.12 환경에서 `rembg[cpu]==2.0.69`와 Pillow를 설치해 실행합니다. 모델은 공식 rembg 배포에서 내려받으며, 실제 이미지 처리는 로컬에서 수행합니다.

2026-09-08: 네 PNG의 알파 채널과 실루엣을 확인했고, 실제 브라우저에서 광장 배치·바닥 정렬·백기석 대화·퀘스트 목록을 확인했습니다. 게임 기존 테스트 39개와 Vite 빌드가 통과했습니다. 광장의 화면 공간 AO는 카드 전체가 사각형으로 음영 처리되는 것을 피하도록 제외했고, 알파를 반영하는 그림자를 사용합니다.

후속 3D 제작에서는 승인된 얼굴·의상·신장 차이를 모델링하고, 대기·손짓·대화 리그와 앞/옆/뒤의 일관성을 검증해야 합니다. 생성 원화는 그 제작 기준입니다.
