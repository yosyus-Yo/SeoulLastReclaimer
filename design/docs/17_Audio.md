# 사운드 목록과 오디오 스타일

## 정체성
현대 도시의 전기, 금속, 차량과 방송 소리를 바탕으로 위상현상을 표현한다. 회수는 공기가 빨려 들어가는 소리와 작은 금속의 정렬음, 잔금막은 겹유리 진동, 해체점은 잠금장치가 순서대로 풀리는 소리다. 마법의 종소리를 모든 능력에 반복하지 않는다. 주인공의 기술마다 시작, 유지, 종료 또는 실패 소리를 구분한다.

## 음악
BGM001 거점은 76BPM의 낮은 피아노와 따뜻한 신스, BGM002 산업 현장은 96BPM의 금속 타악과 낮은 드론, BGM003 보스는 120BPM의 반복 리듬과 불안정한 박자를 사용한다. BGM004 피난 도시는 68BPM의 공명 현악, BGM005 공동 실험은 104BPM, BGM006 최종전은 128BPM, BGM007 귀환은 거점 주제를 변주한다. 음원은 아직 제작되지 않았으며 목록은 sound_list.csv의 의뢰 사양이다.

## 반응형 음악
explore, danger, combat, boss, aftermath 상태로 분리한다. 같은 곡의 분위기층과 타악층을 동기화하고 한 마디 경계에서 전환한다. 잦은 상태 변경을 막기 위해 최소 4초 체류를 둔다. 보스 사망 후 즉시 승리 팡파르를 재생하지 않고 구조 완료 확인 뒤 안정된 주제로 전환한다.

## 믹스
Master, Music, SFX, Voice, UI, Ambience 버스를 분리한다. 대사 재생 시 음악 4dB, 환경 3dB ducking을 0.1초에 적용하고 0.4초에 복원한다. 큰 폭발 중에도 보스 위험음과 회수 완료음이 묻히지 않게 우선순위를 둔다. 헤드폰 야간 모드에서는 저역과 동적 범위를 줄인다. 오디오 소스 최대 동시 48개를 초기값으로 하며 중요한 경고를 유지하고 장식 환경음부터 제거한다.

## 파일 사양
원본 WAV PCM 48kHz 24bit를 요청한다. 짧은 위치 효과음은 mono, 음악과 환경 베드는 stereo다. 음악 루프는 시작과 끝 클릭 없이 제작하고 intro와 loop를 분리한다. 소스 true peak −1dBTP 이하를 제작 기준으로 두되 전체 게임의 지각 음량은 실제 믹스 테스트로 결정한다. 개별 효과음을 모두 동일 LUFS로 정규화하지 않는다.

## 보이스
VS는 태경, 기석, 서린의 핵심 대사 약 30라인과 전투 반응을 우선한다. 본편은 제한된 주요 장면 보이스와 전체 자막을 계획한다. 배우 계약에는 게임과 홍보물의 사용 범위 및 추가 녹음 조건을 명시한다. 실존 인물의 음성을 복제하는 방식은 계획하지 않는다. 이번 패키지는 보이스 파일 대신 대사와 감정 지시를 제공한다.

## 재생 정책
발소리는 표면별 asphalt, concrete, metal로 나누고 최소 3변형을 순환한다. 회수 완료음은 0.12초 내 여러 토큰을 모으면 하나로 합쳐 과도한 소리를 막는다. 경고음은 위험 표식 등장과 같은 시점에 재생한다. 일시정지 시 게임 오디오는 pause하고 UI만 유지한다. 씬 전환 시 이전 환경음 핸들이 남지 않아야 한다.
