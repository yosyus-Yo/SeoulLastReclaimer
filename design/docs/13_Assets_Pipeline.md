# 에셋 목록과 반입 파이프라인

## 산출물 구분
asset_register.csv는 실제 제작해야 할 리소스의 목록이며 상태 Planned는 파일이 존재한다는 의미가 아니다. 생성 콘셉트는 Concept 상태로 별도 기록한다. 런타임 모델과 텍스처, UI, VFX, 음원은 제작과 엔진 검수가 필요하다. 환경 프롭과 재질을 조합하여 맵을 만들며 맵마다 모든 리소스를 새로 만들지 않는다.

## 명명
파일명은 종류_ID_설명_변형_LOD_용도의 영문 소문자와 숫자로 구성한다. 예시는 chr_tk01_body_a_lod0.fbx, tex_tk01_body_a_basecolor.png, anim_tk01_reclaim_loop.fbx, env_ev01_wall_4m_a.fbx, prp_pr004_shelf_a.fbx, vfx_sk003_shield.prefab, aud_sfx_reclaim_01.wav다. 작업 버전은 소스 폴더에서 v001처럼 기록하고 런타임 주소 ID는 버전이 바뀌어도 유지한다.

## 폴더
SourceArt/Characters, Environments, Props, UI, VFX, Audio를 DCC 소스로 관리한다. 게임 프로젝트에서는 Assets/SLR/Art, Audio, Data, Prefabs, Scenes, Scripts 아래에 반입한다. 대형 바이너리는 Git LFS 사용을 제안하고 .meta 파일은 항상 함께 관리한다. 자동 생성 JSON은 Generated에 두고 수동 편집하지 않는다.

## 환경 모듈
벽 2m와 4m, 바닥 2×2m, 문 폭 2.4m, 층고 3.6m를 모듈 기준으로 한다. pivot은 벽 하단 모서리, 바닥 모서리, 캐릭터 발밑, 회전 프롭 힌지다. 충돌체는 시각 메시보다 단순하게 만들고 움직이는 프롭에는 복잡한 비볼록 메시 콜라이더를 사용하지 않는다. 각도 고정 시점에서 카메라를 가리는 벽에는 FadeOccluder 태그와 대체 shadow 정책을 적용한다.

## 프롭 우선 목록
PR001 배송 상자, PR002 플라스틱 팔레트, PR003 배전함, PR004 철제 선반, PR005 지게차, PR006 컨베이어, PR007 화물 셔터, PR008 안전 기둥, PR009 작업등, PR010 소화기, PR011 실외기, PR012 통제선, PR013 회수 차량, PR014 의료 가방, PR015 대피 표지, PR016 이동 배터리, PR017 개찰구, PR018 스크린도어, PR019 변압기, PR020 앵커 링을 계획한다. VS는 PR001~016을 우선하되 PR013은 단순 배경 모델로 제작한다.

## 반입 순서
DCC에서 축과 단위 적용, 재질 이름 확인, FBX 및 PNG 내보내기, Unity 반입 프리셋, LOD와 충돌체 지정, 조명 테스트, 실제 쿼터뷰 캡처, 성능 측정 순으로 진행한다. 모든 캐릭터는 회색 배경 테스트 씬과 EV01 테스트 씬 두 곳에서 검수한다. 소스 라이선스와 AI 생성 여부를 리소스 레코드에 기록한다.

## UI와 VFX 규격
UI 아이콘은 128×128 PNG RGBA, 주요 도식 아이콘은 256×256 원본, 메뉴 그림은 목표 화면 크기의 2배 이내로 제한한다. 폰트는 한글 포함 글리프와 상업 배포 허용 라이선스를 확인한 파일만 포함한다. VFX 텍스처는 256 또는 512 크기 우선, 반복 노이즈는 256, flipbook은 1024 상한 초기 목표다. 프레임 분할과 알파 방식은 리소스 메타데이터에 명시한다.

## 수락 기준
누락 텍스처 0, 잘못된 축 0, 음수 스케일 0, 비정상 실루엣과 장갑 좌우 오류 0, 지정된 머티리얼 슬롯 초과 0을 반입 전 검사한다. 주인공 LOD0 최대 머티리얼 3, NPC 2를 목표로 한다. 본편 에셋 총량은 asset_register와 backlog에서 추적하고 추가 리소스는 일정과 메모리 예산을 함께 검토한다.
