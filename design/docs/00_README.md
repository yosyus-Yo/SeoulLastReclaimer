# 서울의 마지막 회수자 제작 패키지

버전 0.1 · 작성일 2026년 9월 7일 · 프리프로덕션 설계 기준

이 패키지는 현대 서울 배경의 2.5D 쿼터뷰 액션 RPG를 개발하기 위한 최초 제작 기준이다. 캐릭터와 환경은 3D이며 이동과 전투 판정은 주로 XZ 지면에서 이루어진다. Windows PC 싱글플레이 유료 게임을 전제로 한다. 게임 실행 파일과 엔진 프로젝트는 이번 산출물에 포함하지 않는다.

## 읽는 순서
01 Pitch, 02 GDD, 03 전투, 04 성장, 05 인벤토리와 경제, 06 레벨, 07 세계관과 전체 시나리오, 08 대사, 09 UIUX 순서로 읽는다. 10부터 13은 캐릭터와 아트, 14부터 16은 기술, 17은 사운드, 18부터 20은 제작 관리, 21부터 26은 QA와 출시 운영 문서다. 27은 근거 자료와 결정 기록, 28은 요청 항목별 산출물 연결표다.

## 무엇이 확정됐는가
이 문서 안에서의 설계 결정은 PC 싱글플레이, 고정 쿼터뷰, 거점과 임무 구조, 본편 6챕터 18개 주 임무, 원작 완결까지의 각색, 주인공 1명 직접 조작, 능동 도식 3슬롯과 권역 1슬롯이다. 이는 사용자 검토와 플레이테스트를 위한 제안 기준이며 실제 제작 승인이나 출시 약속을 의미하지 않는다.

첫 제작 대상 VS는 M001 물류센터 임무 20분이다. 본편은 주 임무당 목표 20~30분, 거점 대화와 전환을 포함해 약 8~10시간을 목표로 한다. 선택 계약과 재도전은 추가 2~4시간이다. 기존 대화의 원작 1~6부만 첫 작품으로 만드는 방안 대신, 이번에는 사용자가 요청한 완결 시나리오를 충족하도록 원작 12부를 6챕터로 압축했다.

## 산출물의 상태
문서와 수치 데이터는 작성된 설계안이다. 밸런스 수치는 가설이며 측정값이 아니다. 캐릭터 보드와 환경 이미지는 AI 생성 콘셉트이고 FBX 모델이나 실제 게임 캡처가 아니다. 정면과 측면의 디테일 차이는 모델러가 텍스트 사양으로 정리해야 한다. 3D 모델, 리그, 애니메이션, 음원, 보이스와 실제 트레일러는 제작 목록과 사양을 제공한다.

플레이테스트 보고서는 미실시 상태의 운영 양식이다. 테스트 결과를 임의로 채우지 않았다. 등급분류는 목표만 제안하며 실제 등급은 미확정이다. 개인정보처리방침과 이용약관은 사업자명과 문의처가 미정인 검토용 초안으로 게시할 수 없다.

## 수정 원칙
문서의 규칙은 GDD, 수치의 기준은 balance.xlsx, 구현 반입 형식은 data의 JSON Schema로 관리한다. 수치 변경 시 엑셀 수정, 내보낸 JSON 갱신, 데이터 검증, 문서 버전 기록 순서로 진행한다. 현재 JSON과 CSV는 v0.1 스냅샷이다. 엑셀을 수정했다고 자동으로 JSON이 바뀌지 않는다.

ID는 M001 임무, LV001 레벨, SK001 도식, EN001 일반 적, BS001 보스, TK01 캐릭터, PR001 프롭, QA001 테스트, BL001 작업 형식이다. ID를 삭제 후 재사용하지 않는다.
