# 마일스톤과 인력 운영

## 계획 기준
핵심 3인과 전문 외주를 기준으로 78주 약 18개월을 가정한다. 역할은 기획 및 프로듀싱 1명, 게임플레이 및 기술 1명, 3D 아트 및 테크니컬 아트 1명이다. 애니메이션, 사운드, UI 보강, 번역과 QA는 시점별 외주로 보완한다. 실제 채용, 숙련도, 자산 구매 가능성은 미확정이다. 1인 개발이면 같은 일정을 유지하지 않고 콘텐츠를 줄인 별도 계획을 세운다.

| 단계 | 주 | 산출물 | 통과 기준 |
|---|---|---|---|
| 프로토타입 | 1~4 | 회색 박스 전투와 회수 | 회수와 지지의 반복이 작동 |
| 버티컬 슬라이스 | 5~12 | M001 완성도 높은 20분 | 외부 테스트와 저장 안전 검증 |
| 알파 | 13~36 | 18임무 전체 진행 가능 | 처음부터 엔딩까지 막힘 없음 |
| 콘텐츠 완성 | 37~56 | 모델과 배경 대체, 전체 대사 | 누락 콘텐츠 0 및 데이터 잠금 |
| 베타 | 57~68 | 성능과 접근성, 외부 QA | 핵심 기준 충족 및 치명적 결함 0 |
| 출시 후보 | 69~76 | 심사와 스토어, 회귀 테스트 | 등급과 권리 검토 및 배포 검증 |
| 골드 | 77~78 | 최종 빌드와 복구 절차 | 출시 승인과 복구 가능한 패키지 |

## 2주 스프린트
월요일 목표와 수락 조건을 정하고 중간 시연, 마지막 통합 테스트를 수행한다. 완료는 코드나 이미지 제출이 아니라 실제 빌드에서 확인되는 상태다. 기획 변경은 Decision ID를 남기고 영향받는 데이터, 에셋, 테스트를 연결한다. backlog.csv의 Planned는 일정 제안이며 착수 증거가 아니다.

## 체험판 상세
1~2주는 이동, 조준, 공격과 카메라, 3~4주는 잔향과 구조 지점, 5~6주는 보스와 저장, 7~8주는 TK01과 EV01 아트, 9~10주는 VFX와 사운드, 11~12주는 외부 테스트와 재조정을 수행한다. 아트와 기술의 중간 산출물은 통합하되 각 역할의 주당 계획 작업을 가용 시간의 70퍼센트 이내로 두어 수정과 회의를 반영한다.

## 본편 결정
12주 시점에 핵심 재미, 제작 속도, 성능을 함께 본다. 목표를 못 맞추면 출시에 필요한 18임무를 그대로 강행하지 않는다. M001을 개선한 뒤 12임무로 압축하는 안, 보스 원형 4종과 변형 2종을 사용하는 안을 비교한다. 완결 서사는 유지하고 반복 탐사와 선택 계약부터 줄인다.
