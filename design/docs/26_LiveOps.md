# 출시 후 운영과 업데이트

## 운영 모델
일회성 유료 싱글플레이 게임이다. 일일 접속 보상이나 기간 한정 성장 과금을 운영하지 않는다. 출시 후 목표는 저장 안정성, 성능, 접근성 개선과 선택 콘텐츠 제공이다. 자체 서버가 없으므로 유지 비용은 고객 지원, 빌드 배포와 콘텐츠 작업 중심이다.

## 일정 제안
출시일부터 2주는 크래시와 진행 차단 수정에 집중한다. 1개월은 입력과 UI, 성능 및 밸런스를 개선한다. 2~3개월에는 회수 기록실과 보스 재도전 기능을 수요와 제작 여력에 따라 검토한다. 4~6개월에는 기존 지역을 활용한 귀환 계약 3개를 검토한다. 이 일정은 아직 공개 약속이 아니며 실제 반응과 자금에 따라 확정한다.

## 이벤트 예시
귀환 기록 주간은 기존 임무의 구조 경로를 다시 발견하는 선택 도전이다. 보상은 작업일지 꾸미기와 외형 후보이며 성능 우위를 주지 않는다. 이벤트 종료 후에도 도전 기록실에서 콘텐츠를 이용할 수 있게 하여 놓칠까 봐 접속해야 하는 부담을 줄인다. 온라인 순위와 계정 추적 없이 로컬 기록으로 구현한다.

## 수익모델
기본 게임 가격은 기획 가정 24800원이다. 사운드트랙은 제작과 권리 정리 후 별도 판매를 검토한다. 확장팩은 새로운 이야기를 제공할 때만 별도 상품으로 계획하고 본편 결말을 유료 추가물에 숨기지 않는다. 인게임 크레딧 판매, 유료 부활, 확률형 아이템은 없다.

## 지원 기준
P0는 발견 즉시 배포 중단 여부를 검토하고 가능한 가장 빠른 수정과 안내를 목표로 한다. 일반 문의는 영업일 기준 3일 안에 최초 답변을 주는 운영 목표를 둔다. 인력 없는 24시간 대응을 약속하지 않는다. 상태 공지는 문제 범위, 임시 조치, 다음 안내 시점을 담는다. 이용자에게 로그 제출을 강제하지 않는다.

## 업데이트 검증
모든 패치는 새로운 콘텐츠 버전과 변경 기록을 가진다. 이전 두 버전 저장의 로드, M001과 M018 진행, 거래와 회수 회귀 테스트를 실행한다. 배포 전 이전 빌드와 저장 백업을 보존한다. 치명적 문제 발견 시 롤백하거나 호환성 수정 빌드를 제공한다. 패치 노트에 미검증 성능 향상을 수치로 쓰지 않는다.
