# 스토어 자료와 출시 준비

이 문서는 미출시 게임의 스토어 문안과 제작 브리프다. 실제 기능 검증 후 게시하며 현재 생성 이미지는 콘셉트 표시 없이 게임 스크린샷으로 사용할 수 없다.

## 한국어 짧은 설명
무너지는 서울에서 적이 남긴 힘을 회수하세요. 도식을 조합해 싸우고, 대피로를 열고, 사람들을 집으로 돌려보내는 2.5D 액션 RPG입니다.

## 한국어 상세 설명
전투가 끝나면 당신의 일이 시작됩니다. 윤태경은 재난 현장의 잔류물을 치우는 회수 기사입니다. 어느 날 안전하다고 알려진 창고에서 힘의 흐름이 거꾸로 움직이는 것을 발견합니다. 버려진 잔향을 읽는 그의 능력은 도시를 떠받치는 시스템의 비밀로 이어집니다.

적의 공격을 관측하고 잔향을 회수해 전투를 이어 가세요. 견인선으로 적과 잔해를 움직이고, 겹겹의 방벽으로 공격과 붕괴를 버티며, 모은 힘을 되돌려 주세요. 성장하면 한 조각을 다루던 능력이 전장의 흐름을 바꾸는 권역으로 확장됩니다.

구로의 물류센터, 지하철 승강장, 아파트와 거대한 앵커 시설을 누비세요. 귀환방재의 동료들과 연구하고, 서로 다른 세계의 피난민을 만나며, 누구의 희생 위에 안전이 세워졌는지 밝혀내세요. 이야기는 서울의 작은 사고에서 두 세계의 경계를 다시 연결하는 결말까지 이어집니다.

계획 기능은 PC 싱글플레이, 키보드 마우스와 게임패드, 한국어 및 영어 자막, 오프라인 진행입니다. 게시 직전 실제 구현 기능만 남겨야 합니다.

## 영어 짧은 설명
Reclaim the power left behind in a fractured Seoul. Combine abilities, fight through unstable city streets, and open a way home in a story driven isometric action RPG.

## 스크린샷 촬영 목록
SHOT01 구로 골목의 실제 HUD와 회수, SHOT02 창고의 견인선 전투, SHOT03 주민 구조 경로, SHOT04 BS001 약점 노출, SHOT05 도식 연구 메뉴, SHOT06 지하철의 공간 이상, SHOT07 위상층 피난 도시를 계획한다. 각 촬영은 실제 빌드에서 1920×1080 이상을 목표로 하며 이미지에 기능을 합성해 과장하지 않는다. 모든 SHOT 파일은 현재 미제작이다. 제공된 환경 보드는 촬영 구도 참고다.

## 캡슐과 타이틀
대표 아트는 왼팔로 파편을 회수하는 태경과 서울의 평범한 골목을 사용한다. 로고와 캐릭터를 따로 보관해 플랫폼별 비율에 맞춘다. 최종 캡슐 크기는 Steamworks의 현재 템플릿을 내려받아 결정한다. 오래된 규격을 고정하지 않는다. 평점, 할인 문구와 플랫폼 로고를 기본 캡슐에 덧붙이지 않는다.

## 60초 트레일러 편집안
0~5초 익숙한 골목과 거꾸로 흐르는 잔향, 5~15초 회피와 회수의 실제 플레이, 15~25초 견인과 잔금막 조합, 25~35초 주민 대피와 귀환방재 동료, 35~47초 지하철 및 위상층, 47~55초 보스와 회수권역, 55~60초 제목과 출시 시점이 확정된 경우의 안내로 구성한다. CS001 스토리보드는 오프닝 참고이며 실제 트레일러 영상은 아직 없다. 마지막 장면과 기석의 죽음은 홍보 스포일러에서 제외한다.

## 국내 등급 준비
대상 플랫폼과 유통 경로를 정한 뒤 적용되는 등급분류 경로를 게임물관리위원회 또는 해당 지정 사업자에게 확인한다. 게임산업법 제21조의 사전 등급분류 원칙과 적용 예외를 실제 배포 형태에 맞춰 검토한다. 본 기획의 표현 목표는 15세 수준이며 실제 등급을 보장하지 않는다. 폭력, 공포, 언어, 선정성, 약물, 사행성 표현을 씬 ID와 영상 시각에 연결한 내부 목록을 준비한다. 신청 양식, 수수료와 기간은 제출 시 최신 안내를 확인한다.

## 심사 자료 묶음
게임 개요, 실행 가능한 심사용 빌드, 조작법, 전체 진행 방법, 주요 표현 영상, 콘텐츠 목록, 사업자 및 권리 증빙을 준비한다. 심사자가 후반 콘텐츠를 볼 수 있는 테스트 세이브 또는 내부 진행 도구를 제공하되 제출 요건에 맞는지 확인한다. 출시 후 표현과 과금 구조 변경은 신고 또는 재분류 필요성을 검토한다.

## 생성형 AI 사용 기록
현재 캐릭터와 환경 콘셉트는 생성형 AI를 사용했다. 최종 게임 또는 스토어에 실제 포함되는 생성 콘텐츠를 추적해 Steam Content Survey에 사실대로 기재한다. 최종 납품에 포함되지 않는 내부 콘셉트와 플레이어에게 제공되는 콘텐츠를 구분한다. 플랫폼 요구는 출처 문서와 제출 시점 안내를 다시 확인한다.
