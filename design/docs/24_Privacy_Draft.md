# 개인정보처리방침 검토 초안

게시 전 필수 입력은 운영 사업자명, 주소, 개인정보 문의 담당자와 연락처, 시행일, 실제 지원 수탁자 및 처리 위치다. 현재 값은 미정이다. 본문은 자체 계정과 자동 분석 SDK가 없는 PC 싱글플레이 설계를 전제로 작성한 초안이며 실제 구현과 데이터 흐름 확인 없이 게시하지 않는다.

## 적용 범위
이 방침은 사업자가 제공하는 서울의 마지막 회수자 게임과 별도 고객 지원 과정에 적용한다. Steam 등 플랫폼이 구매, 계정, 결제와 배포를 위해 독립적으로 처리하는 정보에는 해당 플랫폼의 정책이 적용된다. 사업자가 플랫폼 데이터를 전달받는 기능을 추가하면 처리 항목을 별도로 명시한다.

## 게임 안에서의 처리
현재 설계는 자체 회원가입과 로그인, 광고 식별자, 자동 원격 분석을 사용하지 않는다. 진행 상황과 설정은 이용자의 기기에 저장하며 사업자 서버로 자동 전송하지 않는다. 이 설명은 구현 목표다. 배포 전 네트워크 검사를 통해 사용 라이브러리의 실제 송신 여부를 확인해야 한다.

## 고객 지원 정보
이용자가 지원 이메일로 문의하면 회신 주소, 문의 내용, 선택 첨부자료를 접수한다. 목적은 문의 응답과 오류 확인이다. 주민등록번호, 결제 수단 전체 정보와 건강정보를 보내지 않도록 안내한다. 지원 완료 후 90일 보관을 내부 제안으로 두며 실제 처리 근거와 보관 필요성, 법령에 따른 별도 보관 여부를 검토해 확정한다. 법정 보관 대상이 있으면 해당 자료와 근거 및 기간을 별도 구분한다.

## 선택 진단 자료
자동 업로드는 기본 설계에 없다. 이용자가 직접 내보낸 진단 자료는 빌드 번호, 오류 코드와 기기 범주 정보로 제한하고 파일 경로, OS 계정명과 개인 문서를 포함하지 않도록 한다. 선택 제출을 거부해도 게임 이용에는 영향이 없다. 실제 기능을 추가하면 수집 항목과 제출 절차를 먼저 공개한다.

## 위탁과 국외 처리
지원 메일 또는 클라우드 제공자를 아직 정하지 않았으므로 수탁자와 국외 처리 여부는 미확정이다. 제공자를 정한 뒤 업체명, 업무, 처리 지역과 필요한 공개 또는 동의 사항을 확정한다. 미정 상태에서 위탁이 없다고 단정하지 않는다. 자체 게임 데이터 서버는 계획하지 않는다.

## 이용자의 요청
이용자는 문의처를 통해 본인 정보의 열람, 정정, 삭제 또는 처리정지 등 법령상 권리 행사를 요청할 수 있다. 사업자는 요청자 확인에 필요한 최소한의 정보만 확인하고 적용 법령에 따라 처리한다. 로컬 저장 데이터는 게임의 저장 슬롯 관리와 운영체제 파일 기능으로 삭제할 수 있게 안내한다.

## 보호와 파기
지원 자료의 접근 권한을 담당자에게 제한하고 전송과 보관 시 적절한 보안 조치를 적용한다. 목적이 끝나고 보관 기간이 지난 자료는 복구하기 어렵게 삭제한다. 백업의 보관 및 삭제 주기는 제공자 결정 후 기재한다. 변경 시 변경 내용과 시행일을 공지한다.

## 출시 전 확인
개인정보 보호법 제30조와 개인정보보호위원회의 최신 작성지침을 기준으로 실제 처리 목록을 검토한다. 이 문서는 구체적 사업자와 처리 환경이 확정되지 않아 법률 검토 및 최종 게시본을 대신하지 않는다. 관련 공식 자료는 27 문서에 있다.
