# UI와 사용자 흐름

## 시각 기준
기준 캔버스 1920×1080, 가장자리 안전 여백 48px, 본문 22px, 핵심 자원 28px, 자막 28~40px 조절을 초기값으로 둔다. 1280×720에서도 주요 조작과 자막이 잘리지 않아야 한다. 고정 픽셀만으로 배치하지 않고 모서리 앵커와 중앙 안전 영역을 사용한다. 제공된 UI_Wireframes.svg는 6개 주요 화면의 와이어프레임, UI_Wireflow.svg는 이동 구조다.

## 전체 흐름
부팅에서 밝기와 자막을 설정한 뒤 타이틀로 간다. 새 게임은 저장 슬롯을 선택하고 CS001로 진입한다. 이어하기는 최신 유효 체크포인트를 불러온다. 거점에서 임무 선택, 장비, 연구, 기록실로 이동한다. 출동 전 도식과 난이도를 확인하고 현장으로 들어간다. 현장에서는 일시정지와 옵션을 열 수 있으며 결과 화면에서 보상과 구조 결과를 확인한 뒤 거점으로 돌아간다.

## HUD
왼쪽 위에는 HP와 체력, 왼쪽 아래에는 에너지, 아래 중앙에는 도식 3개와 권역 슬롯을 둔다. 오른쪽 위에는 현재 필수 목표 하나와 구조 인원, 필요 시 제한시간을 둔다. 잔향은 월드 아이콘과 회수 가능 윤곽으로 표시하고 화면 가장자리에서 중요 구조 위치를 안내한다. 주 목표는 최대 2줄로 제한한다. 인벤토리 전체를 전투 화면에 노출하지 않는다.

## 연구 화면
왼쪽에는 도식 목록, 중앙에는 현재 기본형과 선택 변형, 오른쪽에는 비용과 작동 예시를 둔다. 잠긴 도식은 필요한 임무와 증거를 표시한다. 구매 전후 성능은 같은 단위로 비교한다. 해금 버튼을 누르면 변경 내용을 보여 주고 장착 여부를 선택한다. 재화 부족은 버튼 옆에서 원인을 설명한다.

## 입력 매핑
WASD 이동, 마우스 조준, 좌클릭 공격, Space 회피, 우클릭 회수, E 상호작용, Q F R 도식, C 권역, Tab 기록 또는 지도, Esc 일시정지다. 패드는 LS 이동, RS 조준, RT 공격, A 회피, LT 회수, X 상호작용, LB RB Y 도식, DpadUp 권역, View 지도, Menu 일시정지다. 모든 핵심 행동은 재매핑 가능해야 한다. 충돌 키는 적용 전 알려 주고 비어 있는 필수 입력도 검출한다.

## 포커스와 메뉴
패드 메뉴는 첫 유효 버튼에 포커스를 둔다. 팝업이 닫히면 열었던 버튼으로 돌아간다. 마우스와 패드 전환 시 안내 아이콘만 바꾸고 선택 상태는 유지한다. 되돌아가기 동작은 항상 이전 화면으로 이동한다. 거래 취소는 지갑과 인벤토리를 바꾸지 않는다. 게임패드 연결 해제 시 일시정지하고 재연결 또는 키보드 사용 안내를 보여 준다.

## 상태와 오류 문구
저장 중에는 작은 회전 표시와 저장 중 문구를 사용한다. 저장 실패 시 저장 공간을 확인해 주세요와 재시도 버튼을 제공하며 기존 저장을 덮어쓰지 않는다. 최신 저장이 손상되면 백업 시각을 보여 주고 복원을 제안한다. 연구 재료 부족은 필요한 합금 3개 중 2개 보유처럼 수량을 말한다. 기술 내부 예외 이름은 사용자 화면에 노출하지 않는다.

## 가독성과 편의
색만으로 적대와 중립을 구분하지 않는다. 적은 뾰족한 경고 프레임, 구조자는 둥근 사람 아이콘이다. 카메라 흔들림 0~100퍼센트, 섬광 낮음, 화면 왜곡 끄기, 진동 끄기를 제공한다. 회수 길게 누르기를 토글로 바꿀 수 있다. 자막에는 화자 이름과 방향성 소리의 텍스트 대체를 제공한다. 메뉴 텍스트 대비 목표는 4.5대1이며 실제 색조합 측정이 필요하다.

## 결과 화면
필수 구조 완료 여부, 귀환 인원, 새 도식 증거, 확정 크레딧과 재료를 표시한다. 빠른 클리어가 구조보다 우선하는 점수 체계를 두지 않는다. 결과 화면 중 종료해도 동일 완료 보상을 한 번만 지급한다. 도전 계약 시간 기록은 선택 정보로 별도 표시한다.
