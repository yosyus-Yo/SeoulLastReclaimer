# 웹 첫 챕터 확장 검증

2026-09-07 · 로컬 웹 개발 서버 127.0.0.1:5178

- 4개 구역: 귀환광장, 구로 물류센터, 구로새빛학교, 태산 기록 보관구역.
- 주요 미션 M001~M003과 동료 의뢰 SQ01~SQ04.
- 기존 전투·이동 29개 + 구역·캠페인·퀘스트 10개 = 자동 테스트 39개 통과.
- 모든 구역의 필수 목표, NPC, 구조 지지점, 출구, 의뢰 물품으로 실제 경로 추종 시뮬레이션을 실행해 도착 확인.
- 3개 미션의 조사→구조/보스→귀환 흐름, 7명/12명 구조 조건, 순차 해금, 최초 보상만 지급, 의뢰 수락/수집/올바른 동료에게 보고를 단위·통합 상태 테스트로 확인.
- 캠페인 저장의 형식·순서·보상 일관성 검사와 복원 확인.
- 실제 브라우저: 광장 J 게시판, M002/M003 잠금, SQ04 의뢰 수락, 학교·기록 보관구역 자유탐방, P 촬영 시 경계 바깥 지면 확인, M001 출동, 미완료 귀환 안내와 광장 복귀 확인.
- 구역 이동과 개발 페이지 재로드 후 SQ04 수락 상태 0/3 유지 확인.
- 브라우저 오류 로그 없음. 전체 세 미션의 수동 브라우저 완주는 아직 수행하지 않았음.

맵 끝에는 이동 경계와 별개로 주변 도로·상가·도시 건물·지면·하늘 돔이 존재한다. 구조 인물은 고정 안전 경로를 사용하며, 새 구역의 일부 모델과 보스 동작은 프로토타입 수준이다. 각 미션은 원안의 20~25분 전체 분량을 완성한 것이 아니라 플레이 가능한 첫 챕터 축약본이다.
