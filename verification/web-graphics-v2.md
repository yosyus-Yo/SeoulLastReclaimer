# 그래픽 2차 개선 검증

2026-09-08 · 로컬 개발 서버 · 기존 Unity와 캠페인 데이터 변경 없음.

## 변경

- 절차형 1K 석재 포장, 잎/가지 메시, 화단 흙과 좌석 테두리.
- 분수의 둥근 석재 테두리, 금속 인레이, 환경광을 받는 잔물결 수면.
- 지평선과 상공의 색이 다른 새벽 하늘. 하늘의 비그림자 속성을 정적 배치 후에도 유지.
- 균형/고화질/성능 우선 예산, 30/60 FPS 제한, 별도 품질 저장.
- 반사/그림자 갱신 제한. 메뉴 30 FPS, 숨김 탭 렌더 건너뛰기.
- 기존 재질 비교에 새 돌 재질 포함, 비교 상태에서 구역 이동 시 분리된 텍스처도 해제.

## 검증 결과

- Node 테스트 43개 통과. 기존 이동/전투/퀘스트 39개와 그래픽 예산/프레임 제한 4개.
- 60/120/144/165Hz 입력 타임스탬프에서 30/60 FPS 제한과 중단 후 복귀 검증.
- Production build 통과. 엔진 포함 비압축 번들 500KB 경고는 유지.
- 실제 브라우저에서 광장 포장·나무·분수 표시, 우클릭 이동, 품질 3단계 전환 확인.
- 물류센터 자유탐방 고화질(SAO 포함)/균형 전환, 광장 재진입 확인.
- 수면 개발 중 clearcoatNormal 선언 순서 오류가 있었으며, 최종 코드에서 선언 후 적용하도록 수정. 수정 이후 확인에서 새 셰이더 오류는 관찰되지 않음.
- 기존 SQ04 의뢰 수락 및 0/3 상태, 보상 0 C 유지.

## 성능 관찰의 범위

같은 로컬 브라우저에서 HUD를 읽은 짧은 관찰값이다. 광장은 균형/고화질 약 60 FPS, 성능 우선·30 제한 30 FPS. 같은 물류센터 자유탐방 시점에서는 고화질 36 FPS, 균형 54 FPS를 표시했다. 정식 평균/최저 프레임 벤치마크나 전투·장시간 발열 테스트가 아니다. CPU/GPU 사용률, 전력, 온도는 측정하지 않았으므로 부하 감소율을 주장하지 않는다. 기본값은 균형과 최대 60 FPS다.
