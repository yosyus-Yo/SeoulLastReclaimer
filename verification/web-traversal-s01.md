# S01 수직 이동 첫 구현 검증

2026-09-08. 검토 문서 `77098ef`를 GitHub main에 푸시한 **뒤** 구현 시작. 이 기록은 초기 이동 검증 범위이며 전체 로드맵 완료 보고가 아니다.

## 구현

- 훈련 구역, 동일 데이터 기반 8개 높이 발판과 낮은 천장/기둥.
- Y/수직 속도/접지/공중 최고점, 몸체 높이·발판 윗면·옆면·천장 충돌.
- 60Hz 논리 스텝과 작은 이동 분할. 모달/로딩/숨김 탭 동안 누적 시간 제거.
- Space 점프, C 회피. 같은 높이 우클릭 이동, 다른 높이 자동 이동 거절.
- 공중 행동·평면 목표 높이 차단. 착지 1회 피해, 대시/방벽·미션 완료 전투 면제와 별도로 낙하 처리.
- 안전 지상 위치 복귀, 무보상 훈련 재시도, 4.8m 낙하 연습 위치 선택.
- 기존 리그를 사용한 임시 공중/착지 포즈, 실제 높이의 바닥 표식·충격 고리·카메라.

## 자동 검증

1. 신규 수직 모듈이 없는 상태에서 테스트를 먼저 실행해 모듈 부재 실패 확인.
2. 구현 후 기존 경로 도착의 부동소수점 오차를 발견하고 목표 근처 극소 오차만 보정.
3. 기존 47개 + 신규 13개 = **60개 통과**.
4. 신규 사례: 30/60 FPS 점프 높이·착지, 발판 옆면/이탈, 천장, 낙하식과 1회 피해, 치명적 낙하/재시도, 광장 안전/위치 복구, 공중 행동 차단, 층간 공격/회수 차단, 발판 우클릭, 맵 경계, 훈련 무보상, 8단 발판 연속 오르기, 논리 시간/일시정지.
5. 신규 테스트만 실행한 커버리지에서 `collision-world.js`는 line 100% / branch 약 91%, `simulation-clock.js`는 line/branch 100%. 이는 전체 렌더러/브라우저 커버리지가 아니다.
6. Production build 통과. 기존 비압축 JS 500KB 초과 경고는 남아 있음.

## 실제 브라우저에서 확인

- J 임무 창의 훈련 진입 버튼, 훈련장 표시.
- Space 입력 후 상승 0.8~0.9m 표시와 실제 공중 자세/바닥 그림자 분리.
- 4.8m 발판 진입 후 접지 4.8m, 카메라 수직 추적.
- C 회피로 발판에서 내려온 후 접지 0.0m, **HP 120→89**, ‘낙하 4.8m · 피해 31’ 표시.
- 훈련 다시 시작 버튼으로 HP 89→120, 접지 0.0m 복원 확인.
- 광장 복귀 후 J에서 기존 400 C, M002 출동 가능/M003 잠금, SQ04 0/3 유지 확인.

## 남은 검증과 한계

- 8개 발판 전체는 실제 이동/점프 함수를 사용하는 자동 시뮬레이션으로 검증했다. 브라우저 키보드 조작으로 8단 전체 수동 완주까지 확인한 것은 아니다.
- 전용 공격/방어/점프 클립, 외벽 등반, 실내, 문, 계단/경사, 움직이는 발판, 완성형 미션 체크포인트는 아직 구현하지 않았다.
- 기존 미션 장애물은 기존 차단 정책을 유지한다. 훈련장에서 높이 표면을 반입하는 구조를 먼저 검증했다.
- 게임 규칙의 공중 전투는 초기 제한 정책이다. 층 사이 조준/원거리 탄도는 후속 입체 전투 단계에서 설계한다.
- 장시간 성능/메모리, 낮은 사양 장치, 완성 모션 품질은 별도 검증이 필요하다.
