# S03 전체 지역 충돌 점검·수정

2026-09-08 · 현재 웹 프로토타입의 5개 지역 대상. 신규 지역/기능 추가가 아니라 공통 충돌 오류 수정이다.

## 원인과 수정

| 확인한 문제 | 원인 | 수정 |
|---|---|---|
| 발판에서 내려오면 옆면에 끼임 | 몸체 옆면 반경 0.3m와 접지 반경 0.15m 불일치. 몸이 아직 지형 위와 겹칠 때 낙하 시작 | 수직 접촉과 옆면에 같은 몸체 범위 사용 |
| 옥상/벽/문/기둥 윗면에서 관통 | 플랫폼 목록만 접지 처리하고 다른 유한 높이 고체의 윗면을 누락 | 유한 높이 충돌체 전체의 윗면으로 수직 충돌 판정. 기존 무한 높이 차단물은 그대로 유지 |
| 정상으로 올라서는 중 벽을 놓으면 끼임 | 등반 전환 중간 위치에서 바로 중력 적용 | 벽을 놓을 때 검증된 외벽 바깥 위치에서 낙하 시작 |
| 이미 겹친 상태에서 모든 이동 차단 | 이전 위치가 유효하다고 가정하고 겹침 해소가 없음 | 가까운 유효 위치로 최소 이동, 불가능하면 안전 지상 위치 복귀. HP/문/회수 진행 보존 |
| 열린 문이 공격 경로를 막음 | 공격의 장애물 검사에 현재 문 상태 누락 | 이동과 같은 문 상태 전달. 별도 전투 테스트로 개폐 차이 검증 |

일반 이동은 겹침 복구로 덮어 통과시키지 않는다. 자동 검사에서 정상 출발의 `collisionRepairs`가 계속 0인지 확인한다. 강제로 만든 기존 겹침 상태에 대해서만 복구를 기대하는 테스트를 따로 둔다.

## 조사 범위

| 지역 | 등록 충돌체 (닫힌 문 포함) | 별도 높이 플랫폼 | 문 | 등반 경로 |
|---|---:|---:|---:|---:|
| 이동 훈련장 | 45 | 34 | 1 | 1 |
| 귀환광장 | 4 | 0 | 0 | 0 |
| 구로 물류센터 | 4 | 0 | 0 | 0 |
| 구로새빛학교 | 4 | 0 | 0 | 0 |
| 태산 기록 보관구역 | 4 | 0 | 0 | 0 |
| 합계 | 61 | 34 | 1 | 1 |

각 지역의 이동 경계도 검사한다. 시각용 원경·나뭇잎·간판 등 충돌체로 등록하지 않은 장식은 별도 지형 충돌체라고 주장하지 않는다. 모든 실제 좌표와 입력 순열을 수학적으로 증명한 것은 아니며, 현재 카탈로그 전역에 같은 체계적 검사를 적용한 결과다.

## 재현 → 회귀 검사

수정 전 신규 점검 테스트 6개 묶음이 모두 실패했다. 대표 재현은 4.8m 발판 동쪽 이탈 후 X 약 6.965~7.0, Y=0에서 몸체가 `step-8`에 겹쳐 8방향 이동과 점프로도 벗어나지 못하는 상태였다. 정상 올라타기 3~6프레임 뒤 놓기에서도 서쪽 벽 내부에 착지했다.

수정 후 `web/tests/collision-audit.test.js`의 10개 묶음과 기존 68개, **총 78개 테스트 통과**:

- 유한 고체 윗면의 8방향 이탈·걷기/달리기/점프·20/30/60 FPS: 1,440조합, 158,400단계 검사.
- 모든 지역 충돌체 옆면/모서리와 맵 경계의 걷기·달리기·점프·회피: 1,700조합, 102,000단계 검사.
- 부착/정상 올라타기 취소: 좌우 위치·전환 프레임 147조합.
- 옥상에서 내려붙는 전환의 취소: 25개 시점.
- 전 지역 고정 난수 혼합 입력: 60,000단계.
- 문틈 개폐, 문/인방 위 낙하, 모서리의 0.001m 이하 오차, 열린 문/닫힌 문의 발사 판정.
- 기존 겹침 위치를 각 지역에 주입한 복구 검증: 체력·회수 목록·문 상태 불변.
- 대표 4.8m 낙하 후 31 피해 유지, 추가 이동 가능, 비정상 위치 복구 사용 없음.

주요 세 검사 묶음만 합쳐 **320,400단계**이며, 등반/문/대표 재현 검사는 별도다. 상단 시작점이 다른 고체 내부이거나 몸체를 놓을 수 없는 위치는 정상 시작점 검사에서 제외하고, 유효한 표면/옆면에서 접근하는 사례와 겹침 복구 사례를 구분한다.

기존 회귀에는 모든 지역의 주요 목표·NPC·의뢰 접근, 계단 왕복, 실내 출입, 등반 완주, 전투·구조·보상·저장, J/P/Esc 입력이 포함된다. Production build와 `git diff --check`도 통과했다.

## 실제 브라우저 검증

- 훈련장의 ‘4.8m 발판에서 낙하 연습’ → C 회피로 가장자리 이탈.
- 접지 0.0m, HP 120→89, ‘낙하 4.8m · 피해 31’ 확인.
- 안전 지점 복귀/훈련 재시작을 누르지 않고 ‘훈련동 입구로 이동’을 실행.
- 기존 끼임 지점에서 실제 경로 이동으로 건물 문 앞에 도착, HP 89 유지 및 E 출입문 안내 확인.
- 전체 지역/프레임 조합은 자동 시뮬레이션으로 검사했다. 브라우저에서 모든 경계점을 일일이 수동 조작한 것은 아니다.

변경 소스: `collision-world.js`(일관된 접지와 겹침 해소), `simulation.js`(겹침 복구 진입), `traversal.js`(안전한 등반 놓기), `combat.js`(동적 문 판정), `world.js`(같은 상태로 지면 표식 계산). 회귀 검사는 `web/tests/collision-audit.test.js`에 있다.

## 후속 유지 규칙

- 새 문/기둥/발판도 공통 충돌 데이터에 등록하고 표시 치수와 일치시킨다.
- 충돌 범위·접지 범위를 각 기능에서 서로 다른 상수로 재정의하지 않는다.
- 정상 움직임 검사에서 자동 복귀 횟수가 증가하면 통과로 처리하지 않는다.
- 새 특수 지형(경사·이동 발판·회전 문·새 등반 경로)은 전용 회귀 사례를 추가한다.
- 이 작업은 로컬 수정이며 원격 커밋·푸시·배포를 수행하지 않았다.
