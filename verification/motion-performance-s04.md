# S04 모션 연속성·렌더링 CPU 최적화

2026-09-09 · 기준 HEAD `393b506` · 로컬 구현. 원격 푸시/배포 없음.

## 확인한 원인

1. 매 렌더 프레임마다 `moving=false`로 시작했다. 고정 물리 스텝이 실행되지 않은 표시 프레임은 이동 중에도 Idle로 판정될 수 있었다. 기존 모션 전환은 `.reset()`을 호출하므로 빠른 재전환 때 보행 위상이 초기화됐다.
2. 등반은 전용 클립 없이 Idle 위에 Euler 각도를 더했다. 실제 Idle 자세가 비대칭이며, 믹서가 값이 같은 트랙의 쓰기를 생략하면 외부에서 더한 각도를 안정적으로 초기화할 수 없었다.
3. 훈련장 긴 우클릭 경로 탐색이 동기적으로 수백 ms 걸렸다. 그 동안 JavaScript 메인 스레드의 렌더/애니메이션도 중단됐다.
4. 적/퀘스트 표시에서 매 프레임 DOM 검색과 변경 없는 텍스트·스타일 갱신, 배열 생성과 드롭 중첩 검색이 반복됐다.

## 적용

- `MotionPresentation`: 마지막 물리 스텝의 실제 이동 속도를 유지한다. 0-step 표시 프레임에서 가짜 정지로 전환하지 않는다. 이전/현재 물리 위치를 보간해 인물과 추적 카메라에만 사용하며 물리 상태 자체는 바꾸지 않는다. 순간 이동·복구·장면 전환·일시정지는 이력을 초기화한다.
- `CharacterAnimator`: Idle/Walk/Run/Climb 액션은 한 번 시작하고 가중치를 부드럽게 변경한다. 보행 주기를 매번 reset하지 않는다. 모션 속도는 실제 이동량에 맞춘다. 이름/UUID 트랙을 같은 뼈 바인딩으로 정규화해 혼합 중 서로 덮어쓰지 않게 한다.
- `createClimbClip`: 실제 GLB의 TPose와 뼈 방향을 기준으로 1.4초 손·반대쪽 무릎 교대 반복 동작을 생성한다. 본 quaternion 트랙만 사용하므로 캐릭터 위치/충돌은 기존 물리가 담당한다. 멈추면 잡고 있는 자세를 유지한다. 모션캡처나 외부 제작 모션을 구매/다운로드한 것은 아니다.
- 점프/착지 추가 자세는 매번 이전 보정을 복원한 뒤 적용한다. 정지/일시정지 중 각도 누적을 방지한다.
- 지상 경로 탐색은 충돌체를 경로당 한 번 준비하고 구간 밖 물체를 제외한다. 기존 8cm 샘플과 고층 접지 판정은 유지한다.
- 적 HP 노드·퀘스트 참조 캐싱, 변경 없는 DOM 쓰기 생략, 숨겨진 라벨 계산 생략, 드롭 중첩 검색 제거. 라벨 위치는 매 렌더 프레임 유지한다.
- 메인 HUD 수치 갱신은 최대 20Hz로 제한하고 상호작용 표식의 위치 갱신은 매 렌더 프레임 유지한다.
- 품질 프리셋/해상도/반사/그림자를 강제로 낮추지 않았다. 이번 수치 개선은 주로 CPU 메인 스레드의 불필요한 작업과 정지 구간에 대한 것이다.

## 측정과 검증

### 경로 탐색 비교 (동일 로컬 Node 환경)

HEAD의 이전 `navigation.js`와 수정본을 같은 현재 지형/상태에서 실행하고 경유점 배열이 동일함을 검사했다.

| 훈련장 목적지 | 이전 | 수정 후 | 경유점 |
|---|---:|---:|---:|
| X28 / Z−14 | 626.80ms | 24.94ms | 동일, 3개 |
| X−12 / Z−14 | 914.37ms | 26.36ms | 동일, 2개 |

별도 하위 에이전트의 반복 측정도 이전 592~1,139ms / 수정 후 20~39ms 범위였다. 이 값은 특정 경로의 CPU 처리 시간이며 모든 장치의 FPS/GPU 사용률/온도 개선율을 의미하지 않는다. 새 지형이 훨씬 커지면 추가 비동기 경로 탐색 검토가 필요하다.

### 회귀 테스트

최종 전체 자동 테스트 **89개 통과**, Production build 및 `git diff --check` 통과. 기존 비압축 번들 500KB 경고는 유지된다.

- 전 지역·문 상태·높이·반경 3,000개 무작위 구간에서 최적화된 충돌 판정이 이전 샘플 방식과 일치.
- 물리 스텝이 없는 표시 프레임, 지터 입력 시간, 순간이동/일시정지 뒤 복귀에서 이동 속도/위치 보간 확인.
- 걷기 재전환 시 재생 시간 유지, 혼합 가중치 합 1, 등반 멈춤/일시정지 중 재생 시간 동결 확인.
- 실제 포함 GLB를 텍스처 없이 재구성해 등반 클립이 기존 뼈에 바인딩되고 양손/발이 교대로 움직이는지 확인. 손은 머리 위/벽 방향으로 뻗고 루프 양 끝 회전이 일치한다.
- 실제 GLB의 걷기와 등반을 함께 재생해 보행 다리 움직임과 등반 자세를 확인. 이름/UUID 혼합의 동일 뼈 공유 바인딩도 별도 회귀로 검사.
- 원본 GLB와 생성 전 원본 리그 자세는 변경하지 않음. 기존 전투·미션·저장·충돌 검사를 유지.

### 브라우저 관찰

- 훈련 진입, 외벽까지 자동 이동, E로 부착 후 새로 팔을 올리고 무릎을 굽힌 자세 표시 확인.
- 확인 시 콘솔 error/warn 없음, 훈련장 HUD 약 60 FPS(프레임 상한 60) 표시.
- 연속 키 누름에 의한 외벽 전체 수동 완주나 장시간/저사양 GPU 벤치마크를 완료한 것으로 간주하지 않는다. 연속 동작은 실제 리그와 믹서를 사용하는 자동 테스트로 검증했다.
