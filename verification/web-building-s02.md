# S02 실내·외벽 등반 검증

2026-09-08. S01 로컬 구현 위에 추가했으며 기존 미션/저장 형식과 Unity는 수정하지 않았다.

## 구현 범위

- 훈련장의 동쪽을 확장하고 12×14m 실내 훈련동, 문, 정비 작업대, 21단 계단과 4.2m 옥상을 구성.
- 문/벽/계단/지붕은 동일한 `training-building-data.js` 데이터로 표시·충돌 구성.
- 문 개폐와 문틈 닫힘 방지, 문 상태를 따르는 평면 경로 탐색.
- 실내 입장 시 지붕·앞쪽 벽 표시만 숨기고 충돌 유지. 실외/옥상 복원.
- 지정 외벽 E 진입, W/S 상하·A/D 좌우, 옥상 올라서기/하단 이탈, E/Space 놓기 및 낙하 피해.
- 시작/종료 이동도 충돌 검사. 등반 중 공격/방어/회피/점프 차단과 짧은 재부착 대기.
- 같은 장면에서 문/체력을 유지하고 훈련 재시작 시 초기화. 캠페인 보상 없음.

## 자동 검증

새 테스트를 모듈 구현 전에 실행해 누락 실패를 확인한 뒤 구현했다.

`npm test`에서 총 68개 통과:

- 기존 이동/전투/미션/수직 이동 60개.
- 문 개폐와 무로딩 실내 진입, 플레이어를 문에 끼우지 않음, 문 상태별 경로, 계단 왕복, 지정 외벽 진입과 행동 차단, 정상/하단 이탈, 놓기/재부착 제한/시간 0, 복구 중 문 상태 유지 8개.
- 계단으로 옥상까지 오르내리기, 외벽 전체 상하 이동은 실제 게임 함수를 쓰는 자동 시뮬레이션으로 검증한다.
- 닫힌 단일 출입구 방의 무의미한 전체 경로 검색을 사전에 거절하고 정적 충돌 데이터를 재사용한다.

## 실제 브라우저 확인

- 훈련동 입구 안내 버튼을 통해 문 앞으로 걸어서 도착.
- E로 출입문 열기, 열린 문 안쪽으로 우클릭 이동.
- HUD ‘훈련동 실내 · 0.0m’, 지붕/앞 벽 가리기, 정비실·작업대·계단 표시 확인.
- 실내에서 열린 출입문을 거쳐 외벽 시작점으로 이동, E 부착과 등반 전용 HUD/벽 가려짐 확인.
- 브라우저 제어의 짧은 단발 W 입력으로는 연속 등반 완주를 확인하지 못했다. 연속 상하 이동과 옥상/하단 이탈은 자동 시뮬레이션으로 검증했으며 수동 키보드 전체 완주 검증과 구분한다.

## 한계

등반은 표시된 한 외벽 경로이며 자유 등반이 아니다. 등반 애니메이션은 전용 제작 클립이 아니라 초기 본 자세 보정이다. 우클릭의 다층 계단 자동 경로, 미션 실내/체크포인트, 적의 등반·실내 전투는 아직 제공하지 않는다. 그림자/반사와 벽 투명화의 추가 다듬기는 후속 품질 작업이다.

이번 작업에서 원격 커밋·푸시·배포는 수행하지 않았다.
